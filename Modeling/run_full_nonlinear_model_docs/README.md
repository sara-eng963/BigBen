# Full Nonlinear Furuta Model - Supporting Documents

This directory contains the documents supporting
[`run_full_nonlinear_model.m`](../run_full_nonlinear_model.m):

- `FURUTA_MODEL_DECISION_GUIDE.pdf` - comparison and model-selection guide.
- `Nonlinear_Derivation.pdf` - full nonlinear derivation and validation record.

The MATLAB script remains the executable full three-inertia nonlinear model.
Its included numerical parameters are synthetic validation values and must be
replaced with measured or CAD-derived values before hardware use.
